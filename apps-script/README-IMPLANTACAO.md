# Código Apps Script legado

Este diretório foi mantido apenas como referência de regras e de auditoria da versão anterior. Não publique este projeto pelo Apps Script: a arquitetura atual usa o HTML gerado em `public/`, a API `netlify/functions/crm.mjs` e o banco Supabase privado.

O código estático preservado aqui é usado por parte dos testes de regressão e pela interface aprovada. Dados de equipe foram removidos da configuração pública. Para configurar, testar e publicar a versão atual, siga o `README.md` e `docs/TRANSFERENCIA.md` na raiz do repositório.
